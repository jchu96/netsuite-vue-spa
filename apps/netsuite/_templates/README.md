# SDF templates

Edit these files to change the generated example. Run `npm run generate -- --force` from the repository root, then `npm run check`. Tests compare regenerated bytes to committed SDF source to detect drift.

- `scripts/`: authenticated Suitelet and read-only RESTlet.
- `objects/`: both script/deployment definitions and the permission-list Hello Record custom record with its dedicated viewer role.
- [Variables](TEMPLATE_VARIABLES.md): configuration, naming and overwrite rules.

No background worker, progress record or mutable business operation is supplied. Add an independently tested worker and authorization model before extending the example with those features.
