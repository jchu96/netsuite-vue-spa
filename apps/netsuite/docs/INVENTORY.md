Both script objects point to real JS files. The Suitelet loads `app/index.html`, produced by the byte-verified frontend build.

No other SDF objects, static local modules, external scripts, translations or account-configuration exports are required. The structural check rejects empty deploy patterns, missing files, malformed XML and invalid generated JavaScript.
