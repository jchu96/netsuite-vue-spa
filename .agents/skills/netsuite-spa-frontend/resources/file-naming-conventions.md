# File Naming Conventions

Use PascalCase.vue for components and views, camelCase.ts for stores/types/helpers, and useCamelCase.ts for composables. Import with relative paths. SuiteScript files use a script type suffix (such as _RL.js or _SL.js); SDF IDs are lowercase with _rl/_sl and at most 40 characters. Template files keep the .template suffix.
